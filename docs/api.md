# API документация RSC Agency

**Базовый URL:** `/leads/api/`

---

## Таблица 1: API для публичной части (клиентские)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/services/` | Список всех активных услуг |
| GET | `/projects/` | Список активных проектов портфолио |
| GET | `/projects/{id}/` | Детальная информация о проекте |
| GET | `/notifications/` | Уведомления текущего пользователя (последние 10) |
| POST | `/notifications/{id}/read/` | Отметить уведомление как прочитанное |
| POST | `/notifications/read-all/` | Отметить все уведомления как прочитанные |
| GET | `/lead/{id}/messages/` | История переписки по заявке |
| GET | `/user/messages/` | Список диалогов текущего пользователя |
| GET | `/lead/{id}/detail/` | Детальная информация о заявке |

---

## Таблица 2: API для админ-панели

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/leads/admin/leads/json/` | Список заявок в JSON (с лимитом) |
| GET | `/leads/admin/leads/stats/` | Статистика по заявкам |
| GET | `/leads/admin/stats/total/` | Общая статистика (клиенты, услуги, проекты, сообщения, сотрудники) |
| GET | `/leads/admin/employees/api/` | Список активных сотрудников с онлайн-статусом |
| GET | `/leads/admin/leads/history/api/` | История действий по заявкам (с лимитом) |
| GET | `/leads/admin/message/{id}/json/` | Детали сообщения в JSON |

---

## Таблица 3: Эндпоинты для чата и ответов

| Метод | Эндпоинт | Описание | Примечание |
|-------|----------|----------|------------|
| POST | `/users/lead/{id}/reply/` | Ответ клиента на заявку (с файлами) | Используется в личном кабинете |
| POST | `/leads/admin/lead/{id}/reply/` | Ответ администратора на заявку (с файлами) | Используется в админ-панели |
| GET | `/leads/admin/lead/{id}/history/` | История изменений заявки в JSON | Возвращает полную историю с вложениями |

---

## Таблица 4: Эндпоинты для массовых операций и экспорта

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/leads/admin/leads/export/` | Экспорт заявок в CSV |
| POST | `/leads/admin/leads/bulk-delete/` | Массовое удаление заявок |
| POST | `/leads/admin/leads/bulk-status/` | Массовое изменение статуса заявок |

---

## Таблица 5: Эндпоинты для управления

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | `/leads/admin/services/{id}/toggle/` | Включение/отключение услуги |
| POST | `/leads/admin/project/{id}/toggle/` | Включение/отключение проекта |
| POST | `/leads/admin/message/{id}/reply/` | Ответ на сообщение с контактной формы |
