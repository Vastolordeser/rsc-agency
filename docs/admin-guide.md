# Руководство администратора RSC Agency

## Вход
/leads/admin/dashboard/

## Дашборд
Статистика по заявкам, клиентам, услугам, проектам

## Управление заявками (/leads/admin/leads/)
- Фильтрация по статусу
- Поиск
- Экспорт CSV
- Изменение статуса
- Ответ клиенту (работает только с файлом .env)

## Управление клиентами (/leads/admin/clients/)
- CRUD операции
- Блокировка/разблокировка

## Управление услугами (/leads/admin/services/)
- CRUD операции
- Включение/отключение

## Управление проектами (/leads/admin/projects/)
- Портфолио
- Включение/отключение

## Управление сотрудниками (/leads/admin/employees/)
- Права: full, view_only, leads_only, clients_only

## Сообщения (/leads/admin/messages/)
- Ответы на сообщения с сайта (работает только с файлом .env)
